# Módulo de Autenticación y Control de Accesos — WORLD GYM

## Roles del Sistema y Niveles de Seguridad
* **Nivel 1 - Administrador (`IdRol = 1`)**: Acceso global irrestricto al sistema, finanzas, empleados, membresías, inventario y configuración.
* **Nivel 2 - Entrenador y Recepcionista (`IdRol = 2, 3`)**: Gestión operativa de asistencias, rutinas, clientes y catálogo.
* **Nivel 3 - Cliente (`IdRol = 4`)**: Acceso público y exclusivo a la Tienda Web y catálogo de membresías, sin acceso al panel administrativo `/dashboard`.
